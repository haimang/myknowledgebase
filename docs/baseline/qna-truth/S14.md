### Q1 — 配置源优先级与 ConfigSnapshot 构造时机

| 项 | 内容 |
|---|---|
| **标题** | 多载体配置如何合并？`ConfigSnapshot` / binding 材料在何时构造且对谁权威？ |
| **Impact** | 决定全系统「哪份配置算数」、可复现性、与 S05–S07 binding freeze 是否打架 |

#### 选项

| 选项 | 摘要 | 要点 |
|---|---|---|
| **A** | **Env 最高 + 运行时任意 merge** | 环境变量与请求 bag 可覆盖一切（含 model/prompt）；无冻结快照；类似 legacy payload_config |

| **C** | **DB registry 为唯一运行时 SSOT** | git 仅 seed；运行期一切读 DB（含可变 active 指针）且允许 mid-flight 重读 |

#### 分层（选项 B 规范意图）

| 层 | 载体 | 用途 | 冲突 |
|---|---|---|---|
| **L0** | git `data/config/**` + code defaults | 非秘密默认值、profile 模板、阈值/batch 默认 | 类型非法 → bootstrap/readiness fail |
| **L1** | DB registry 指针行 | prompt hash、model_catalog、adapter_bindings、schema digests、workflow revision 指针 | 同 version 异 digest → **fail-loud** |
| **L2** | env（+ S16 secret 解析） | **仅**部署拓扑（`vllm.base_url`、路径根等）与 secret **值**；**禁止** env 静默改写 prompt 正文、`model definition_digest`、schema digest、workflow revision（**RC Δ1**） | secret 不进 git/DB 正文列 |
| **L3** | 白名单 task/execution override（Q3） | 仅允许键；进入 materialize 材料 | 未知键 **reject** |
| **L4** | **Frozen binding / ConfigSnapshot** | materialize 后该次执行的 **唯一权威** | 后续 L0–L3 变更 **不影响** 本 Execution |

**构造时机（B）**：`resolve_for_new_execution` / ProcessCommand materialize **一次**；产出 `config_snapshot_digest`（或并入既有 `*_binding_digest` / `command_input_digest` 材料，不另立平行 SSOT）。  
**Workflow**：版本/compiled digest **只读自 S03 七表**（T-O-268），S14 不 merge 第二 workflow JSON。

#### RECOMMENDED：`B`

**Reasoning**  
1. 服从 T-O-269 binding freeze 与 T-O-276 载体族：需要 **显式分层** 与 **L4 冻结**，不能 A 式任意 merge（N-07）。  
2. C 把 DB 当可漂移运行时 SSOT 并 mid-flight 重读 → 直接破坏 S05-T025 / S06-T003。  
3. D 与 D04 `mkb_*` 表、S11 catalog 已冻真相冲突。  
4. B 对齐 leaf-worker：bootstrap 灌 L1；运维用 L2 调拓扑；业务可复现靠 L4 digest。  
5. Fail-closed：L1 digest 冲突 / 缺指针 = readiness 或 materialize 失败，禁止 silent 降级到「最新文件」。

**内部证据**：T-O-269/275/276；EC-02/41/42/43；S03-T017；S11-E03 解析后锁定 binding；N-06/N-07。

**残差风险**：digest 材料字段闭集需与 Q5/Q6 对齐；多 profile 时 L0 文件布局需 formal 钉路径约定。

**RC 注记（Δ1）**：12-factor 区分 deploy-varying（env）与 internal 非变配置（可 git）；OpenGitOps/K8s immutable 支持 L4 冻结。维持 **B**。
